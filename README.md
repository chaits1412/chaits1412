## Featured Work

### [Data on Demand — Quick-Commerce Gap Analysis](https://github.com/chaits1412/Quick-commerce-analytics)

A diagnostic analytics project on a simulated quick-commerce business — **150,000 searches, 78,936 orders**. Python → BigQuery SQL → root-cause analysis → Power BI.

- Found a **54.28% product availability gap**, concentrated in identifiable SKUs
- Investigated one underperforming dark store (DS009: **6.13% on-time** vs. a ~42% network average) across four candidate causes — peak-hour load, distance, workload, picking time — and **ruled out all four**, documenting it as unresolved rather than forcing a conclusion
- **26 documented BigQuery queries**, each with its business purpose and result recorded inline
- 3-page interactive Power BI diagnostic dashboard

`Python` `BigQuery` `SQL` `Power BI` `DAX`
